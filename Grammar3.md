# Grammatik: der Gebrauch von „es"

### 1. es als Personalpronomen

Ersetzt ein **neutrales Nomen** (das ...) — genau wie er (der) und sie (die).

| Nomen | Ersetzt durch es (Beispiel) |
| --- | --- |
| das Buch (Nominativ) | Wo ist das Buch? – Es liegt auf dem Tisch. |
| das Buch (Akkusativ) | Ich lese das Buch. – Ich lese es. |
| das Kind | Das Kind schläft. – Es schläft schon lange. |

---

### 2. es als Ersatz für eine Phrase / einen ganzen Satz

es verweist auf etwas bereits Gesagtes — eine Aussage, ein Adjektiv nach sein/werden/bleiben, keine konkrete Sache.

| Situation | Beispiel |
| --- | --- |
| Verweis auf eine ganze Aussage | Er kommt heute nicht. – Ich habe es schon gewusst. |
| Verweis auf ein Adjektiv nach sein | Bist du müde? – Ja, ich bin es. |
| Verweis auf ein Nomen nach werden | Sie wird Ärztin. – Ihre Schwester ist es auch schon. |

---

### 3. es ist + Adjektiv/Nomen (unpersönliche Ausdrücke)

es hat hier **keinen konkreten Bezug** — es ist ein reines Formsubjekt, weil der deutsche Satz immer ein Subjekt braucht.

| Beispiel |
| --- |
| Es ist wichtig, pünktlich zu sein. |
| Es ist kalt draußen. |
| Es ist schade, dass du nicht kommst. |
| Es ist Zeit zu gehen. |

---

### 4. Feste Wendungen mit es

es ist hier **fester Bestandteil des Ausdrucks** — man kann es nicht weglassen oder ersetzen.

| Wendung | Bedeutung | Beispiel | Englisch / Situation |
| --- | --- | --- | --- |
| es gibt + Akk. | existieren | Es gibt heute keinen Unterricht. | there is/are — etwas existiert oder findet statt |
| es geht (jmdm.) + Adv. | jmds. Zustand | Wie geht es dir? – Es geht mir gut. | how are you / I'm doing well — nach dem Befinden fragen/antworten |
| es geht um + Akk. | Thema sein | In dem Film geht es um Freundschaft. | it's about — das Thema von etwas nennen |
| es gefällt (jmdm.) | mögen | Es gefällt mir hier sehr gut. | I like it — Gefallen ausdrücken |
| es tut (jmdm.) leid | bedauern | Es tut mir leid, dass ich zu spät bin. | I'm sorry — sich entschuldigen/bedauern |
| es kommt darauf an | abhängen von | Es kommt darauf an, wie viel Zeit wir haben. | it depends — keine feste Antwort geben |
| es handelt sich um | Thema/Inhalt sein | Es handelt sich um ein Missverständnis. | it concerns/is about — formell den Inhalt erklären |
| es fehlt (jmdm.) an + Dat. | Mangel haben | Es fehlt ihm an Geduld. | to lack something — einen Mangel beschreiben |
| es klingelt / es klopft | Geräusch | Es klingelt an der Tür. | the doorbell is ringing / there's a knock — ein Geräusch ohne Verursacher nennen |

---

### 5. es bei Naturphänomenen, Wetter und Zeit

Reines **Formsubjekt ohne jeden Bezug** — es gibt kein „echtes" Subjekt, das es ersetzen könnte.

| Bereich | Beispiel |
| --- | --- |
| Wetter | Es regnet. / Es schneit. / Es blitzt und donnert. |
| Temperatur | Es ist heiß. / Es wird kalt. |
| Uhrzeit | Es ist drei Uhr. |
| Wochentag/Jahreszeit | Es ist Montag. / Es wird Herbst. |
| Helligkeit | Es wird dunkel. |

---

### 6. es als (Platzhalter-)Subjekt in Position 1

Wenn kein anderes Element den Satz einleitet, füllt es die Position 1, damit das Verb an Position 2 stehen kann. Dieses es trägt **keine Bedeutung** und **verschwindet**, sobald ein anderes Element (Subjekt, Zeitangabe, Ort ...) Position 1 übernimmt.

| Mit es (Position 1 frei) | Ohne es (Position 1 besetzt) |
| --- | --- |
| Es kommt ein Mann ins Zimmer. | Ein Mann kommt ins Zimmer. |
| Es wurde gestern viel gelacht. | Gestern wurde viel gelacht. |
| Es waren einmal drei Brüder. | (feste Märchenformel — es bleibt hier immer, Ausnahme) |

> **Regel:** es fällt weg, sobald ein anderes Element Position 1 einnimmt — außer bei festen Formeln wie „Es war einmal ...".

---

### 7. es als (echtes) Objekt

es steht als **Akkusativobjekt** und verweist auf ein Nomen oder eine ganze Idee/Handlung.

| Beispiel |
| --- |
| Ich weiß es noch nicht. |
| Ich kann es nicht glauben. |
| Er hat es gut gemeint. |
| Sie hat es eilig. |

---

### 8. es in Nebensätzen mit ob/dass (Korrelat)

es steht im Hauptsatz als Platzhalter (**Korrelat**) für einen folgenden dass-/ob-Satz.

| Beispiel                          |
| --------------------------------- |
| Es ist gut, dass du kommst.       |
| Es ist unklar, ob er kommt.       |
| Ich finde es gut, dass du kommst. |

> **Regel — Nebensatz zuerst, kein es:** Steht der dass-/ob-Satz **vor** dem Hauptsatz (nimmt also selbst Position 1 ein), entfällt das es.

| dass-/ob-Satz zuerst (kein es) |
| --- |
| Dass du kommst, ist gut. |
| Ob er kommt, ist unklar. |
| Dass du kommst, finde ich gut. |

---

### 9. es + zu-Infinitiv (Korrelat)

Genau wie bei 8: es steht als Platzhalter (**Korrelat**) für einen folgenden zu-Infinitiv-Satz.

| Beispiel |
| --- |
| Es ist wichtig, pünktlich zu kommen. |
| Es macht Spaß, neue Sprachen zu lernen. |
| Ich finde es schön, hier zu sein. |

> **Regel — Nebensatz zuerst, kein es:** Steht der zu-Infinitiv-Satz **vor** dem Hauptsatz, entfällt das es — genau wie bei dass/ob (Regel 8).

| zu-Infinitiv-Satz zuerst (kein es) |
| --- |
| Pünktlich zu kommen ist wichtig. |
| Neue Sprachen zu lernen macht Spaß. |
| Hier zu sein finde ich schön. |
