# Grammar: Alternatives to Passive + müssen/können (Passiversatzformen)

Instead of saying "Passiv + können/müssen", German has three shorter alternative structures. They all replace the same idea but aren't fully interchangeable — read the table below carefully.

### The three structures

| # | Structure | How to build it | Expresses |
| --- | --- | --- | --- |
| 1 | **sein + zu + Infinitiv** | sein (conjugated) + subject ... + zu + Infinitiv (at the end) | können **or** müssen — context decides |
| 2 | **sein + adjective (-bar/-lich)** | sein + verb stem + -bar (sometimes -lich) | können **only** |
| 3 | **sich lassen + Infinitiv** | subject + sich + lassen (conjugated) + Infinitiv (at the end) | können **only** |

> Only structure 1 (sein + zu + Infinitiv) can express müssen. Structures 2 and 3 only ever mean "can be done" — there's no -bar-adjective or sich-lassen version for necessity.

---

### Side-by-side examples

| Original (Passiv + Modal) | sein + zu + Infinitiv | -bar/-lich adjective | sich lassen | English |
| --- | --- | --- | --- | --- |
| Der Bus **kann** repariert werden. | Der Bus **ist zu reparieren**. | Der Bus **ist reparierbar** (or: reparabel). | Der Bus **lässt sich reparieren**. | The bus can be repaired. |
| Die Hausaufgabe **muss** erledigt werden. | Die Hausaufgabe **ist zu erledigen**. | — (no -bar form for müssen) | — (no lassen form for müssen) | The homework must be done. |
| Der Text **kann** leicht verstanden werden. | Der Text **ist** leicht **zu verstehen**. | Der Text **ist** leicht **verständlich**. | Der Text **lässt sich** leicht **verstehen**. | The text can easily be understood. |
| Das Problem **kann nicht** gelöst werden. | Das Problem **ist nicht zu lösen**. | Das Problem **ist unlösbar**. | Das Problem **lässt sich nicht lösen**. | The problem can't be solved. |
| Die Datei **muss** bis Freitag gesendet werden. | Die Datei **ist bis Freitag zu senden**. | — | — | The file must be sent by Friday. |
| Diese Suppe **kann** getrunken werden. | Diese Suppe **ist zu trinken**. | Diese Suppe **ist trinkbar**. | Diese Suppe **lässt sich trinken**. | This soup can be drunk. |

---

### -bar, -lich, and -abel/-ibel — example list

Three suffix families build these "can be done" adjectives. **-bar** is by far the most productive (works with almost any transitive verb); **-lich** is a smaller, closed set (often with a stem change); **-abel/-ibel** attaches to Latin-origin/loan verbs and often exists side by side with a -bar version.

**-bar (most common, use this by default)**

| Verb        | Adjective    | English           |
| ----------- | ------------ | ----------------- |
| reparieren  | reparierbar  | repairable        |
| lösen       | lösbar       | solvable          |
| essen       | essbar       | edible            |
| trinken     | trinkbar     | drinkable         |
| lesen       | lesbar       | readable          |
| hören       | hörbar       | audible           |
| sehen       | sichtbar     | visible           |
| machen      | machbar      | doable/feasible   |
| brauchen    | brauchbar    | usable            |
| vergleichen | vergleichbar | comparable        |
| erreichen   | erreichbar   | reachable         |
| vermeiden   | vermeidbar   | avoidable         |
| heilen      | heilbar      | curable           |
| tragen      | tragbar      | portable/bearable |
| bezahlen    | bezahlbar    | affordable        |
| waschen     | waschbar     | washable          |
| denken      | denkbar      | conceivable       |

**-lich (smaller group, often irregular)**

| Verb | Adjective | English |
| --- | --- | --- |
| verstehen | verständlich | understandable |
| erklären | erklärlich | explainable |
| zerbrechen | zerbrechlich | fragile/breakable |
| verzeihen | verzeihlich | forgivable |
| ersetzen | (un)ersetzlich | (ir)replaceable — almost always used negated: unersetzlich |
| glauben | (un)glaublich | (un)believable — almost always used negated: unglaublich |

**-abel/-ibel (Latin loanwords, more formal)**

| Verb/Base    | Adjective   | English                    |
| ------------ | ----------- | -------------------------- |
| reparieren   | reparabel   | repairable (= reparierbar) |
| akzeptieren  | akzeptabel  | acceptable                 |
| diskutieren  | diskutabel  | debatable                  |
| tolerieren   | tolerabel   | tolerable                  |
| respektieren | respektabel | respectable                |
| Praxis       | praktikabel | practicable/workable       |

> **Negation with all three:** just add un- to the front — unlösbar, unverständlich, unakzeptabel.

---

### How to tell können vs. müssen in "sein + zu + Infinitiv"

This structure alone is ambiguous — context (adverbs, deadlines, tone) tells you which meaning is intended:

| Signal                                                        | Meaning                                              | Example                                                             |
| ------------------------------------------------------------- | ---------------------------------------------------- | ------------------------------------------------------------------- |
| words like leicht, schwer, kaum, gut (ease/difficulty)        | usually können                                       | Der Text ist leicht zu lesen. (can easily be read)                  |
| a deadline, rule, or instruction (bis ..., sofort, unbedingt) | usually müssen                                       | Der Bericht ist bis Montag abzugeben. (must be handed in by Monday) |
| plain statement, no extra clue                                | often defaults to müssen/necessity in formal writing | Die Regeln sind zu befolgen. (the rules must be followed)           |

---

### Negation

| Structure             | Negated form    | Meaning                                     |
| --------------------- | --------------- | ------------------------------------------- |
| sein + zu + Infinitiv | + nicht         | Das ist nicht zu ändern. (can't be changed) |
| -bar adjective        | un- + adjective | unlösbar, unreparierbar, unsichtbar         |
| sich lassen           | + nicht         | Das lässt sich nicht ändern.                |

---

### Quick rule of thumb

- Only need to express **können**? Use whichever sounds most natural: **-bar/-lich adjective** or **sich lassen** — both are clean and unambiguous.
- Need to express **müssen**? Your only option here is **sein + zu + Infinitiv** — add a deadline/rule-word if you want the necessity reading to be unmistakable.
