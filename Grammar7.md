# Grammatik: um zu/damit, ohne zu/dass, statt zu/dass & Modalverben in allen Zeiten

## Teil 1: um...zu, ohne...zu, statt...zu (+ Nebensatz-Varianten)

<span style="color:red">*Achtung:*</span> „um dass" gibt es **nicht**! Der Nebensatz-Partner von „um...zu" heißt **damit**, nicht „um dass". Nur ohne und statt haben eine echte dass-Variante.

**Grundregel für alle drei:** gleiches Subjekt in Haupt- und Nebensatz → **zu + Infinitiv**. Verschiedene Subjekte → **Nebensatz** (damit/ohne dass/statt dass), Verb am Ende.

### 1. um...zu / damit — Zweck, Ziel

| | |
| --- | --- |
| Kasus (als Präposition + Nomen) | um + Akkusativ („um die Ecke") |
| Verwendet für | den Zweck/das Ziel einer Handlung nennen |
| Gleiches Subjekt | um ... zu + Infinitiv |
| Verschiedene Subjekte | damit + Nebensatz |

| Zeitbezug | Struktur | Beispiel |
| --- | --- | --- |
| Gegenwart/Zukunft, gleiches Subjekt | um ... zu + Infinitiv | Ich lerne jeden Tag, um die Prüfung zu bestehen. |
| Vergangenheit, gleiches Subjekt (selten) | um ... Partizip II + zu + haben/sein | Er trainierte hart, um die Meisterschaft gewonnen zu haben. |
| verschiedene Subjekte, Gegenwart | damit + Präsens | Ich spreche laut, damit alle mich hören. |
| verschiedene Subjekte, Vergangenheit | damit + Präteritum/Perfekt | Er sprach laut, damit alle ihn hören konnten. |

### 2. ohne...zu / ohne dass — negativer Begleitumstand

| | |
| --- | --- |
| Kasus (als Präposition + Nomen) | ohne + Akkusativ („ohne mich") |
| Verwendet für | etwas passiert nicht, obwohl es erwartet wird |
| Gleiches Subjekt | ohne ... zu + Infinitiv |
| Verschiedene Subjekte | ohne dass + Nebensatz |

| Zeitbezug                            | Struktur                               | Beispiel                                                  |
| ------------------------------------ | -------------------------------------- | --------------------------------------------------------- |
| Gegenwart/Zukunft, gleiches Subjekt  | ohne ... zu + Infinitiv                | Er verlässt das Haus, ohne die Tür abzuschließen.         |
| Vergangenheit, gleiches Subjekt      | ohne ... Partizip II + zu + haben/sein | Er verließ das Haus, ohne die Tür abgeschlossen zu haben. |
| verschiedene Subjekte, Gegenwart     | ohne dass + Präsens                    | Sie geht vorbei, ohne dass er es bemerkt.                 |
| verschiedene Subjekte, Vergangenheit | ohne dass + Präteritum/Plusquamperfekt | Sie ging vorbei, ohne dass er es bemerkte.                |

### 3. statt...zu / statt dass — Alternative, Ersatzhandlung

| | |
| --- | --- |
| Kasus (als Präposition + Nomen) | (an)statt + Genitiv, umgangssprachlich Dativ („statt des Autos" / „statt dem Auto") |
| Verwendet für | etwas passiert anstelle von etwas anderem |
| Gleiches Subjekt | statt ... zu + Infinitiv |
| Verschiedene Subjekte | statt dass + Nebensatz |

| Zeitbezug | Struktur | Beispiel |
| --- | --- | --- |
| Gegenwart/Zukunft, gleiches Subjekt | statt ... zu + Infinitiv | Er sieht fern, statt seine Hausaufgaben zu machen. |
| Vergangenheit, gleiches Subjekt | statt ... Partizip II + zu + haben/sein | Sie kaufte das Auto, statt es vorher getestet zu haben. |
| verschiedene Subjekte, Gegenwart | statt dass + Präsens | Er hilft mir, statt dass er selbst arbeitet. |
| verschiedene Subjekte, Vergangenheit | statt dass + Präteritum | Er half mir, statt dass er selbst arbeitete. |

## Teil 2: Modalverben in Präsens, Präteritum, Perfekt, Futur I

### Präsens

| Person | können | müssen | wollen | sollen | dürfen | mögen |
| --- | --- | --- | --- | --- | --- | --- |
| ich | kann | muss | will | soll | darf | mag |
| du | kannst | musst | willst | sollst | darfst | magst |
| er/sie/es | kann | muss | will | soll | darf | mag |
| wir | können | müssen | wollen | sollen | dürfen | mögen |
| ihr | könnt | müsst | wollt | sollt | dürft | mögt |
| sie/Sie | können | müssen | wollen | sollen | dürfen | mögen |

### Präteritum

| Person | können | müssen | wollen | sollen | dürfen | mögen |
| --- | --- | --- | --- | --- | --- | --- |
| ich | konnte | musste | wollte | sollte | durfte | mochte |
| du | konntest | musstest | wolltest | solltest | durftest | mochtest |
| er/sie/es | konnte | musste | wollte | sollte | durfte | mochte |
| wir | konnten | mussten | wollten | sollten | durften | mochten |
| ihr | konntet | musstet | wolltet | solltet | durftet | mochtet |
| sie/Sie | konnten | mussten | wollten | sollten | durften | mochten |

### Perfekt

haben (immer, nie sein) konjugiert + [Partizip II **oder** Ersatzinfinitiv] am Satzende:

| Person | haben |
| --- | --- |
| ich | habe |
| du | hast |
| er/sie/es | hat |
| wir | haben |
| ihr | habt |
| sie/Sie | haben |

Steht das Modalverb **allein** (kein zweites Verb), nimmt man das echte Partizip II. Steht ein **Vollverb** dabei, nimmt man den **Ersatzinfinitiv** (Infinitiv statt Partizip II) — gleiche Regel wie bei hören/sehen/lassen (siehe [Grammar1](Grammar1.md) §2).

| Modalverb | Partizip II (allein) | Ersatzinfinitiv (mit Vollverb) | Beispiel mit Vollverb |
| --- | --- | --- | --- |
| können | gekonnt | können | Ich habe das nicht machen können. |
| müssen | gemusst | müssen | Ich habe früh aufstehen müssen. |
| wollen | gewollt | wollen | Ich habe ins Kino gehen wollen. |
| sollen | gesollt | sollen | Ich habe das machen sollen. |
| dürfen | gedurft | dürfen | Ich habe nicht rausgehen dürfen. |
| mögen | gemocht | mögen | Ich habe das nicht essen mögen (selten, meist ersetzt durch „wollte nicht"). |

### Futur I

werden konjugiert + Infinitiv(-cluster) am Satzende:

| Person | werden |
| --- | --- |
| ich | werde |
| du | wirst |
| er/sie/es | wird |
| wir | werden |
| ihr | werdet |
| sie/Sie | werden |

| Modalverb | Beispiel (allein) | Beispiel (mit Vollverb) |
| --- | --- | --- |
| können | Ich werde das können. | Ich werde das machen können. |
| müssen | Ich werde das müssen. | Ich werde früh aufstehen müssen. |
| wollen | Ich werde das wollen. | Ich werde ins Kino gehen wollen. |
| sollen | Ich werde das sollen. | Ich werde das machen sollen. |
| dürfen | Ich werde das dürfen. | Ich werde rausgehen dürfen. |
| mögen | Ich werde das mögen. | (mit Vollverb ungebräuchlich) |

> Bei zwei Infinitiven am Satzende steht das Modalverb **immer zuletzt**: ... Vollverb-Infinitiv + Modalverb-Infinitiv.
