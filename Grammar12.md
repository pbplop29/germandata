# Grammar: Trennbare und untrennbare Verben (durch-, über-, um-, unter-, wieder-)

Most prefixes are fixed: **be-, ent-, emp-, er-, ge-, miss-, ver-, zer-** are always inseparable, and **ab-, an-, auf-, aus-, ein-, mit-, vor-, zu-** etc. are always separable. But five prefixes are "dual" — the exact same verb can be **either** separable or inseparable, usually with a **different meaning**: **durch-, über-, um-, unter-, wieder-**.

### Two rules to tell them apart

| Rule | Trennbar | Untrennbar |
| --- | --- | --- |
| Partizip II | **ge-** inserted between prefix and stem | **no ge-** at all — identical to the infinitive stem pattern |
| Word stress (Aussprache) | stress on the **prefix** | stress on the **verb stem** |

> ⚠️ **The trap:** in a Nebensatz or with a Modalverb, the prefix moves back next to the stem in both versions — so the *written* form can look **100% identical** (e.g. "dass er das Buch **wiederholt**" could be either meaning). In that position, **only the spoken stress** tells them apart. The Perfekt/Partizip II is where the spelling finally splits for certain (ge- or not).

---

### Overview: 5 pairs, 5 prefixes

| Prefix | Trennbar (stress on prefix) | Meaning | Untrennbar (stress on stem) | Meaning |
| --- | --- | --- | --- | --- |
| durch- | **DURCH**fahren *(Ptz. II: durchgefahren)* | to pass through without stopping | durch**FAH**ren *(Ptz. II: durchfahren)* | to travel/drive through (a place) |
| über- | **ÜBER**setzen *(Ptz. II: übergesetzt)* | to ferry across | über**SETZ**en *(Ptz. II: übersetzt)* | to translate |
| um- | **UM**fahren *(Ptz. II: umgefahren)* | to run over / knock down | um**FAH**ren *(Ptz. II: umfahren)* | to drive around / avoid |
| unter- | **UNTER**stellen *(Ptz. II: untergestellt)*, reflexiv | to take shelter | unter**STELL**en *(Ptz. II: unterstellt)* | to accuse / imply / subordinate |
| wieder- | **WIEDER**holen *(Ptz. II: wiedergeholt)* | to fetch/bring back again | wieder**HOL**en *(Ptz. II: wiederholt)* | to repeat |

---

## durchfahren

### Trennbar — to pass through without stopping (stress: **DURCH**fahren)

| Type | Example |
| --- | --- |
| Hauptsatz | Der Zug fährt am Hauptbahnhof durch. |
| Nebensatz | Ich habe gehört, dass der Zug am Hauptbahnhof durchfährt. |
| mit Modalverb | Der Zug soll am Hauptbahnhof durchfahren. |

### Untrennbar — to travel/drive through a place (stress: durch**FAH**ren)

| Type | Example |
| --- | --- |
| Hauptsatz | Wir durchfahren die Wüste. |
| Nebensatz | Ich weiß, dass wir die Wüste durchfahren. |
| mit Modalverb | Wir müssen die Wüste durchfahren. |

---

## übersetzen

### Trennbar — to ferry across (stress: **ÜBER**setzen)

| Type | Example |
| --- | --- |
| Hauptsatz | Die Fähre setzt die Passagiere über. |
| Nebensatz | Ich glaube, dass die Fähre die Passagiere übersetzt. |
| mit Modalverb | Die Fähre muss die Passagiere übersetzen. |

### Untrennbar — to translate (stress: über**SETZ**en)

| Type | Example |
| --- | --- |
| Hauptsatz | Sie übersetzt das Buch ins Deutsche. |
| Nebensatz | Ich weiß, dass sie das Buch ins Deutsche übersetzt. |
| mit Modalverb | Sie will das Buch ins Deutsche übersetzen. |

---

## umfahren

### Trennbar — to run over / knock down (stress: **UM**fahren)

| Type | Example |
| --- | --- |
| Hauptsatz | Er fährt aus Versehen das Verkehrsschild um. |
| Nebensatz | Ich habe gesehen, dass er das Verkehrsschild umfährt. |
| mit Modalverb | Er könnte das Verkehrsschild aus Versehen umfahren. |

### Untrennbar — to drive around / avoid (stress: um**FAH**ren)

| Type | Example |
| --- | --- |
| Hauptsatz | Er umfährt die Baustelle. |
| Nebensatz | Ich hoffe, dass er die Baustelle umfährt. |
| mit Modalverb | Er kann die Baustelle umfahren. |

---

## unterstellen

### Trennbar — to take shelter, reflexiv (stress: **UNTER**stellen)

| Type | Example |
| --- | --- |
| Hauptsatz | Wir stellen uns bei Regen unter. |
| Nebensatz | Ich schlage vor, dass wir uns bei Regen unterstellen. |
| mit Modalverb | Wir sollten uns bei Regen unterstellen. |

### Untrennbar — to accuse / imply / subordinate (stress: unter**STELL**en)

| Type | Example |
| --- | --- |
| Hauptsatz | Sie unterstellt ihm eine Lüge. |
| Nebensatz | Ich finde es unfair, dass sie ihm eine Lüge unterstellt. |
| mit Modalverb | Sie sollte ihm keine Lüge unterstellen. |

---

## wiederholen

### Trennbar — to fetch/bring back again (stress: **WIEDER**holen)

| Type | Example |
| --- | --- |
| Hauptsatz | Er holt das Buch bei seinem Freund wieder. |
| Nebensatz | Ich habe gehört, dass er das Buch bei seinem Freund wiederholt. |
| mit Modalverb | Er will das Buch bei seinem Freund wiederholen. |

### Untrennbar — to repeat (stress: wieder**HOL**en)

| Type | Example |
| --- | --- |
| Hauptsatz | Sie wiederholt die Frage. |
| Nebensatz | Ich finde es gut, dass sie die Frage wiederholt. |
| mit Modalverb | Sie muss die Frage wiederholen. |

---

> **Perfekt check:** Er hat das Buch **wiedergeholt**. (trennbar — fetched it back) vs. Sie hat die Frage **wiederholt**. (untrennbar — repeated) — this is the one place the spelling never lies.
