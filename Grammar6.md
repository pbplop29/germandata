# Grammatik: Vermutungen mit Modalverben

Sie **könnte** krank sein. = Sie ist **vielleicht** krank. — Modalverb statt Adverb, gleiche Bedeutung.

### 1. Konjugation

| Person    | müssen (Präsens) | müssen (Konj. II) | dürfen (Konj. II) | können (Präsens) | können (Konj. II) |
| --------- | ---------------- | ----------------- | ----------------- | ---------------- | ----------------- |
| ich       | muss             | müsste            | dürfte            | kann             | könnte            |
| du        | musst            | müsstest          | dürftest          | kannst           | könntest          |
| er/sie/es | muss             | müsste            | dürfte            | kann             | könnte            |
| wir       | müssen           | müssten           | dürften           | können           | könnten           |
| ihr       | müsst            | müsstet           | dürftet           | könnt            | könntet           |
| sie/Sie   | müssen           | müssten           | dürften           | können           | könnten           |

---

### 2. Wann benutzt man was? (Sicherheitsskala)

Je weiter oben, desto sicherer — genau wie der Pfeil im Bild.

| Sicherheit               | Modalverb     | Alternative mit Adverb                   | Beispiel                                                     |
| ------------------------ | ------------- | ---------------------------------------- | ------------------------------------------------------------ |
| 100 % (sehr sicher)      | muss          | sicher / bestimmt                        | Sie muss krank sein. = Sie ist sicher krank.                 |
| ca. 90 %                 | müsste        | höchstwahrscheinlich / fast sicher       | Sie müsste krank sein. = Sie ist höchstwahrscheinlich krank. |
| ca. 70 %                 | dürfte        | wahrscheinlich / vermutlich / sicherlich | Sie dürfte krank sein. = Sie ist wahrscheinlich krank.       |
| < 50 % (nicht so sicher) | könnte / kann | vielleicht / eventuell / möglicherweise  | Sie könnte krank sein. = Sie ist vielleicht krank.           |


---

### 3. Beispiele: maskulin, feminin, neutrum, Plural

Gleiches Szenario für alle Zeilen, damit die Stufen vergleichbar sind: **Warum ist der/die Kollege/-in nicht im Büro?**

| Sicherheit | Maskulin (der Kollege) | Feminin (die Kollegin) | Neutrum (das Kind) | Plural (die Kollegen) |
| --- | --- | --- | --- | --- |
| 100 % | Der Kollege muss krank sein. | Die Kollegin muss krank sein. | Das Kind muss krank sein. | Die Kollegen müssen krank sein. |
| ca. 90 % | Der Kollege müsste krank sein. | Die Kollegin müsste krank sein. | Das Kind müsste krank sein. | Die Kollegen müssten krank sein. |
| ca. 70 % | Der Kollege dürfte krank sein. | Die Kollegin dürfte krank sein. | Das Kind dürfte krank sein. | Die Kollegen dürften krank sein. |
| < 50 % | Der Kollege könnte krank sein. | Die Kollegin könnte krank sein. | Das Kind könnte krank sein. | Die Kollegen könnten krank sein. |

> Das Genus des Subjekts (der/die/das) ändert die Verbform **nicht** — nur die Zahl (Singular/Plural) tut das (muss → müssen).

### 4. Vermutungen über die Vergangenheit (Partizip II + haben/sein)

**Struktur:** Modalverb (konjugiert) + Partizip II + haben/sein (Infinitiv, am Satzende) — kein „zu", weil Modalverben nie mit zu stehen (siehe [Grammar2](Grammar2.md) §2a). haben/sein-Wahl wie im normalen Perfekt (siehe [Grammar2](Grammar2.md) §4).

| Sicherheit | mit haben | mit sein |
| --- | --- | --- |
| 100 % | Er muss das Buch gelesen haben. | Er muss schon gegangen sein. |
| ca. 90 % | Er müsste das Buch gelesen haben. | Er müsste schon gegangen sein. |
| ca. 70 % | Er dürfte das Buch gelesen haben. | Er dürfte schon gegangen sein. |
| < 50 % | Er könnte das Buch gelesen haben. | Er könnte schon gegangen sein. |

---

### 5. Vermutungen im Passiv (werden / worden)

**Grundform ohne Modalverb** — so sieht das Passiv aus, bevor eine Vermutung dazukommt:

| Zeit | Struktur | Beispiel |
| --- | --- | --- |
| Präsens Passiv | werden + Partizip II | Das Auto wird repariert. |
| Perfekt Passiv | ist/sind + Partizip II + **worden** | Das Auto ist repariert worden. |

> Im Perfekt Passiv steht immer **sein** (nie haben) als Hilfsverb — genau wie bei Modalverben oben ist es auch hier **worden**, nicht geworden.

**Mit Modalverb (Vermutung):**

**Präsens Passiv** (Vermutung über etwas, das gerade passiert): Modalverb + Partizip II + **werden**
**Passiv der Vergangenheit** (Vermutung über eine abgeschlossene Handlung): Modalverb + Partizip II + **worden** + sein

| Sicherheit | Passiv Präsens (läuft gerade) | Passiv Vergangenheit (abgeschlossen) |
| --- | --- | --- |
| 100 % | Das Auto muss repariert werden. | Das Auto muss repariert worden sein. |
| ca. 90 % | Das Auto müsste repariert werden. | Das Auto müsste repariert worden sein. |
| ca. 70 % | Das Auto dürfte repariert werden. | Das Auto dürfte repariert worden sein. |
| < 50 % | Das Auto könnte repariert werden. | Das Auto könnte repariert worden sein. |

> <span style="color:red">**Achtung:**</span> Im Passiv-Perfekt heißt es immer **worden** (nicht geworden) + sein. „geworden" benutzt man nur, wenn werden ein Vollverb ist: „Er ist Arzt **geworden**." (nicht: worden)
