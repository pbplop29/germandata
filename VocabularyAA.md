## zwar

> **admittedly, but**

| | zwar ... aber | zwar ... doch | zwar ... jedoch | zwar ... allerdings |
| --- | --- | --- | --- | --- |
| Rule | Standard, neutral | Same meaning, slightly literary | Same meaning, more formal/written | Same meaning, formal, often used alone without a preceding "zwar" too |
| German | Er ist <span style="color:purple">*zwar*</span> reich, <span style="color:purple">*aber*</span> nicht glücklich. | Sie war <span style="color:purple">*zwar*</span> müde, <span style="color:purple">*doch*</span> sie blieb bis zum Schluss. | Die Kosten sind <span style="color:purple">*zwar*</span> gestiegen, die Nachfrage <span style="color:purple">*jedoch*</span> auch. | Der Plan ist <span style="color:purple">*zwar*</span> riskant, <span style="color:purple">*allerdings*</span> auch vielversprechend. |
| English | He's <span style="color:purple">*admittedly*</span> rich, <span style="color:purple">*but*</span> not happy. | She was <span style="color:purple">*admittedly*</span> tired, <span style="color:purple">*yet*</span> she stayed until the end. | Costs have <span style="color:purple">*admittedly*</span> risen — <span style="color:purple">*however*</span>, so has demand. | The plan is <span style="color:purple">*admittedly*</span> risky — <span style="color:purple">*though*</span> also promising. |

> **to be exact**

|         | und zwar                                                                                  |
| ------- | ----------------------------------------------------------------------------------------- |
| Rule    | Adds a precise detail right after a vaguer statement — "namely / > **to be exact**"       |
| German  | Ich komme morgen, <span style="color:purple">*und zwar*</span> um 10 Uhr.                 |
| English | I'm coming tomorrow — <span style="color:purple">***to be exact***</span>, at 10 o'clock. |

## quasi

> **practically, virtually**

| | quasi + Adjektiv | quasi + Verb | quasi + Nomen |
| --- | --- | --- | --- |
| Rule | Something is almost entirely true/complete | An action is basically/practically already done | Treats something as nearly equivalent to a category — "practically a..." |
| German | Das Projekt ist <span style="color:purple">*quasi*</span> fertig. | Er hat <span style="color:purple">*quasi*</span> schon zugesagt. | Sie ist <span style="color:purple">*quasi*</span> die Chefin hier. |
| English | The project is <span style="color:purple">*practically*</span> finished. | He's <span style="color:purple">*practically*</span> already agreed. | She's <span style="color:purple">*practically*</span> the boss here. |

> **so to speak, kind of**

| | quasi (Hedge/Filler, ugs.) |
| --- | --- |
| Rule | Softens a claim in casual speech — hedges without really changing the meaning |
| German | Ich hab <span style="color:purple">*quasi*</span> keine Zeit mehr. |
| English | I <span style="color:purple">*basically*</span> have no time left. |

## aufgeregt

> **excited, nervous**

| | aufgeregt (excited) | aufgeregt (nervous) |
| --- | --- | --- |
| Rule | Positive anticipation before something good — a trip, event, surprise | Anxious apprehension before something stressful — exam, interview, difficult talk |
| German | Die Kinder sind <span style="color:purple">*aufgeregt*</span> vor der Geburtstagsfeier. | Er ist <span style="color:purple">*aufgeregt*</span> vor der Prüfung. |
| English | The kids are <span style="color:purple">*excited*</span> about the birthday party. | He's <span style="color:purple">*nervous*</span> before the exam. |

## beschäftigen / sich beschäftigen mit

> **employ, preoccupy, occupy oneself with**

| | beschäftigen (employ) | beschäftigen (preoccupy) | sich beschäftigen mit (engage with) |
| --- | --- | --- | --- |
| Rule | Transitive — to give someone a job, have staff | Transitive — something occupies someone's thoughts/attention | Reflexive + mit — to spend time engaging with/working on a topic |
| German | Die Firma <span style="color:purple">*beschäftigt*</span> 200 Mitarbeiter. | Diese Frage <span style="color:purple">*beschäftigt*</span> mich schon lange. | Ich <span style="color:purple">*beschäftige mich mit*</span> Philosophie. |
| English | The company <span style="color:purple">*employs*</span> 200 staff. | This question has been <span style="color:purple">*occupying*</span> me for a long time. | I'm <span style="color:purple">*engaging with*</span> philosophy. |

> **busy**

| | beschäftigt sein |
| --- | --- |
| Rule | Partizip II used as a plain adjective — a state of being busy/occupied, not an action |
| German | Ich bin gerade <span style="color:purple">*beschäftigt*</span>. |
| English | I'm <span style="color:purple">*busy*</span> right now. |
