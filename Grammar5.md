# Grammar: Konjunktiv II

### 1. Overview of forms

(German grammar terms — Infinitiv, Partizip II, Präteritum, Konjunktiv II — are kept as the German names, since those are the actual concepts being studied.)

| Verb | Infinitiv | Partizip II | Präteritum | würde + Infinitiv | Konjunktiv II |
| --- | --- | --- | --- | --- | --- |
| **Auxiliary verbs** | | | | | |
| haben | haben | gehabt | hatte | würde haben* | hätte |
| sein | sein | gewesen | war | würde sein* | wäre |
| werden | werden | geworden | wurde | würde werden | würde |

| Verb | Infinitiv | Partizip II | Präteritum | würde + Infinitiv | Konjunktiv II |
| --- | --- | --- | --- | --- | --- |
| **Modal verbs** | | | | | |
| können | können | gekonnt | konnte | würde können* | könnte |
| müssen | müssen | gemusst | musste | würde müssen* | müsste |
| wollen | wollen | gewollt | wollte | würde wollen* | wollte |
| sollen | sollen | gesollt | sollte | würde sollen* | sollte |
| dürfen | dürfen | gedurft | durfte | würde dürfen* | dürfte |
| mögen | mögen | gemocht | mochte | würde mögen* | möchte |

| Verb | Infinitiv | Partizip II | Präteritum | würde + Infinitiv | Konjunktiv II |
| --- | --- | --- | --- | --- | --- |
| **Common verbs** | | | | | |
| finden | finden | gefunden | fand | würde finden | fände |
| brauchen | brauchen | gebraucht | brauchte | würde brauchen | bräuchte** |
| wissen | wissen | gewusst | wusste | würde wissen* | wüsste |
| geben (es gibt) | geben | gegeben | gab | würde geben | gäbe |
| kommen | kommen | gekommen | kam | würde kommen | käme |
| gehen | gehen | gegangen | ging | würde gehen | ginge |

\* is basically never used in practice — you always use the real Konjunktiv II form instead (hätte, wäre, könnte ...).
\** "bräuchte" isn't fully standard (brauchen is a weak verb → technically "würde brauchen" is correct), but it's extremely common in everyday speech.

> **Rule of thumb:** weak/regular verbs (kaufen, machen, spielen ...) → use **würde + infinitive**, because the real Konjunktiv II form would be identical to the Präteritum and therefore confusing. haben, sein, modal verbs, wissen, and strong verbs → mostly use the **real form** with an umlaut.

### 2. Konjunktiv II in the past

**Formation:** hätte/wäre (Konjunktiv II of haben/sein) + Partizip II — the same haben/sein choice as in the normal Perfekt (see [Grammar2](Grammar2.md) §4).

**Used for:** something that did **not** happen in the past — unreal wishes about the past, unreal past conditionals, regret/reproach ("should have done").

**Key contrast — present wish vs. past wish:**

| Type | Example |
| --- | --- |
| Present/general (wish about now) | Ich wünschte, ich hätte mehr Zeit.<br>*I wish I had more time.* |
| Past (wish about something already over) | Ich wünschte, ich hätte mehr Zeit gehabt.<br>*I wish I had had more time.* |

**All verbs from Part 1 — present vs. past compared:**

| Verb | Konjunktiv II present (example) | Konjunktiv II past (example) |
| --- | --- | --- |
| haben | Ich hätte gern mehr Geld.<br>*I'd like to have more money.* | Ich hätte gern mehr Geld gehabt.<br>*I would have liked to have more money.* |
| sein | Ich wäre gern zu Hause.<br>*I would like to be at home.* | Ich wäre gern zu Hause gewesen.<br>*I would have liked to have been at home.* |
| werden | Er würde gern Arzt werden.<br>*He would like to become a doctor.* | Er wäre gern Arzt geworden.<br>*He would have liked to become a doctor.* |
| können | Ich könnte dir helfen.<br>*I could help you.* | Ich hätte dir helfen können.<br>*I could have helped you.* |
| müssen | Ich müsste eigentlich lernen.<br>*I really should be studying.* | Ich hätte eigentlich lernen müssen.<br>*I really should have studied.* |
| wollen | Ich wollte das nicht sagen.<br>*I didn't want to say that.* | Ich hätte das nicht sagen wollen.<br>*I wouldn't have wanted to say that.* |
| sollen | Du solltest mehr schlafen.<br>*You should sleep more.* | Du hättest mehr schlafen sollen.<br>*You should have slept more.* |
| dürfen | Ich dürfte das nicht tun.<br>*I shouldn't be allowed to do that.* | Ich hätte das nicht tun dürfen.<br>*I shouldn't have done that.* |
| mögen | Ich möchte das nicht essen.<br>*I wouldn't like to eat that.* | Ich hätte das nicht essen mögen (selten; meist umschrieben mit „wollte nicht").<br>*I wouldn't have liked to eat that (rare; usually rephrased with "didn't want to").* |
| finden | Ich fände das gut.<br>*I would find that good.* | Ich hätte das gut gefunden.<br>*I would have found that good.* |
| brauchen | Ich bräuchte mehr Zeit.<br>*I would need more time.* | Ich hätte mehr Zeit gebraucht.<br>*I would have needed more time.* |
| wissen | Ich wüsste eine Lösung.<br>*I would know a solution.* | Ich hätte eine Lösung gewusst.<br>*I would have known a solution.* |
| geben (es gibt) | Es gäbe eine Lösung.<br>*There would be a solution.* | Es hätte eine Lösung gegeben.<br>*There would have been a solution.* |
| kommen | Ich käme gern mit.<br>*I would like to come along.* | Ich wäre gern mitgekommen.<br>*I would have liked to come along.* |
| gehen | Ich ginge jetzt gern.<br>*I would like to go now.* | Ich wäre jetzt gern gegangen.<br>*I would have liked to have gone already.* |

> **Subordinate-clause trap with modal verbs:** with the Ersatzinfinitiv (können, müssen, wollen, sollen, dürfen + main verb), hätte goes **before** the double infinitive in a subordinate clause, not at the end: „..., weil ich das nicht hätte machen können." *(..., because I couldn't have done that.)* — not: „..., weil ich das nicht machen können hätte."

### 3. When do you use Konjunktiv II?

| Situation | Structure | Example |
| --- | --- | --- |
| Unreal wish | Ich wünschte, ... / Wenn ... doch nur ... | Ich wünschte, ich hätte mehr Zeit. / Wenn ich doch nur mehr Zeit hätte!<br>*I wish I had more time. / If only I had more time!* |
| Something didn't happen (past irrealis) | hätte/wäre + Partizip II | Wenn ich früher losgefahren wäre, hätte ich den Zug nicht verpasst.<br>*If I had left earlier, I wouldn't have missed the train.* |
| Politeness | könnte / hätte gern / würde | Könnten Sie mir bitte helfen? Ich hätte gern einen Kaffee.<br>*Could you please help me? I would like a coffee.* |
| Suggestion | könnten / sollten | Wir könnten heute Abend ins Kino gehen.<br>*We could go to the cinema tonight.* |
